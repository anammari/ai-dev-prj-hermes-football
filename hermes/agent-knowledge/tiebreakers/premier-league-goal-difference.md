# Premier League table order and tiebreakers

The table is ordered by points, then goal difference, then goals scored.

If a decisive outcome — the title, relegation, or qualification for another competition — is still
level after points, goal difference and goals scored, Rule C.17 applies:

1. points won in the matches between the tied clubs;
2. away goals scored in those head-to-head matches;
3. a play-off on a neutral ground, arranged by the Board.

So goal difference is the first separator for the table, and head-to-head only comes in for a
decisive place that remains level after the normal sorting. This is the opposite order from La Liga,
where head-to-head goal difference comes first.

## What this note will not say

It does not predict a play-off, and it does not give the tiebreak rules of other competitions.
