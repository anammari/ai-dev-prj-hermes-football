# La Liga tiebreakers

La Liga uses head-to-head results before overall goal difference, which is the opposite of the
Premier League.

**Two clubs level on points.** The order is:

1. goal difference in the matches between the two clubs;
2. overall goal difference in the competition;
3. goals scored in the competition;
4. fair-play ranking;
5. a match on neutral ground arranged by the RFEF.

**Three or more clubs level on points.** The tied clubs are first put into a mini-league using only
the matches among them. If that separates them, it decides the positions. If two clubs remain level
in the mini-league, the same list applies: head-to-head goal difference, overall goal difference,
goals scored, fair play, then a neutral match.

The rule is Article 10 of the RFEF's 2026/27 competition rules. LaLiga's own general regulation sets
the points system but not these tiebreak criteria.

## What this note will not say

It does not predict a neutral play-off, and it does not use the Premier League's goal-difference-first
order.
