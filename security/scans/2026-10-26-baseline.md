# Security baseline — 2026-10-26 (M6)

A redacted snapshot of the first full scan after M6, so a later reader can see what the tools said
without a directory of raw reports. Raw output stays in `scans/latest/` (ignored) and in CI artifacts.

## Findings fixed during the review

- **OpenTelemetry API 1.38.0 / CVE-2026-114603.** Fixed in 1.45.1. The pinned instrumentation pair had
  to move with it (SDK 1.45.1 ↔ instrumentations 0.66b1); the versions are now pinned together in
  `pyproject.toml` and the timeout/telemetry tests still pass.
- **pip 25.0.1 advisories.** The image's installer is upgraded before dependencies are installed; it
  is a build tool, not a runtime dependency, but a permanent exception was not worth it.
- **Owner DSN in the API container.** `backend` now receives an `agent_readonly` DSN; the owner
  password is only in `db`, `ingest`, `migrate` and the test fixtures. Held by
  `tests/test_compose_policy.py`.
- **MCP bearer comparison.** `==` replaced with `hmac.compare_digest` over the rendered header.

None.

## What is not scanned

- The host's Docker images other than this project (`make scan-images` targets the three built images).
- The notes corpus for factual accuracy (that is the eval, not a security scan).
- The Telegram or Ollama cloud providers; the egress policy is in `_docs/product-spec.md` §4 and
  decisions 0003/0007/0010.
